    About these numbers
    • Data comes from Claude Code transcripts in ~/.claude/projects: the CLI, the desktop app's Code tab and IDE extensions, including subagents. Duplicate log lines for the same API response are merged. Chats on claude.ai and in the desktop chat tab aren't stored locally and aren't included.
    • API $ uses public per-token API prices (cache writes 1.25×/2× input, cache reads discounted). On a Pro/Max/Team plan you don't pay this; it shows the value of what you used.
    • Background is usage Claude Code counted in its own per-session cost records but never wrote to a transcript (titles, summaries, background Haiku calls): the record's totals minus what the transcript logged up to that point. It has no exact timestamps, so it is placed at the record's time, priced with 5-minute cache writes, and not counted as API calls.
    • The 5-hour window is estimated locally: it opens at your first message, floored to the UTC hour, and lasts five hours. The exact plan % and reset times only come from Fetch live limits, which uses your Claude Code login.
    • vs previous compares the selected range with the same length of time just before it. Budgets you set are stored in this browser only.
